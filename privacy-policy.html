Privacy Policy — Yinniy

Operator: Yinniy  |  Application: 拾柒 Yinniy  |  Last updated: November 27, 2026

1. What this app is

拾柒 Yinniy is a personal AI assistant used by a single person (the operator) for personal use only. It reads the operator's own Pinterest boards and Pins to understand the operator's image and design preferences, so it can help discover and create images the operator likes.

2. Data the app accesses

The app reads, through the Pinterest API with the operator's own authorization: the operator's account information, boards, and Pins, including secret boards and secret Pins. It only accesses data belonging to the operator's own Pinterest account.

3. What the app does not do

The app does not publish, create, modify, or delete any content on Pinterest. It does not access any other user's data. It does not share, sell, or disclose any data to any third party. It does not run advertisements and does not use cookies or tracking tools.

4. How data is used

Data read from the operator's account is used only to understand the operator's image preferences and to provide personal assistance. No data is used for any other purpose.

5. Revoking access and deleting data

The operator can revoke the app's access at any time in Pinterest settings. After revocation, the app can no longer read the account. Stored preference summaries can be deleted on request.

6. Contact

Questions about this policy can be sent through the operator's GitHub profile: https://github.com/yinniy-923.

隐私政策 — Yinniy

运营方：Yinniy  |  应用：拾柒 Yinniy  |  最后更新：2026 年 11 月 27 日

1. 应用说明

拾柒 Yinniy 是运营方个人使用的 AI 助手，仅供单人个人使用。它读取运营方本人的 Pinterest 画板和 Pin，了解运营方的图片喜好，以便帮助发现和创作运营方喜欢的图片。

2. 访问的数据

应用通过 Pinterest API、在运营方本人授权下读取：运营方本人的账号信息、画板和 Pin，包括私密画板和私密 Pin。应用只访问运营方本人 Pinterest 账号的数据。

3. 应用不做的事

应用不在 Pinterest 上发布、创建、修改或删除任何内容；不访问任何其他用户的数据；不与任何第三方分享、出售或披露任何数据；不投放广告，不使用 Cookie 和追踪工具。

4. 数据的使用方式

从运营方账号读取的数据仅用于了解运营方的图片喜好并提供个人帮助，不用于任何其他目的。

5. 撤销授权与删除数据

运营方可以随时在 Pinterest 设置中撤销应用的授权。撤销后，应用无法再读取该账号。已保存的偏好摘要可根据要求删除。

6. 联系方式

有关本政策的问题，可通过运营方的 GitHub 主页联系：https://github.com/yinniy-923。
