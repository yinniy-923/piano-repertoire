## 重要说明
这里的“一至十级”是方便选曲的参考难度梯度，并非中国音乐家协会、英皇 ABRSM 或其他机构的官方曲目单。各机构分级不同，同一作品的不同编配难度也可能差别很大。部分高级作品明显超出常规考级范围，仅作为长期挑战或选段研究。

选曲时同时考虑读谱、节奏、双手协调、技术、音乐表达、篇幅和个人练习时间。准备考试请以对应机构当年有效的官方曲目表为准。

## 乐谱与版权
本项目提供曲名与学习建议，不收录未经授权的完整乐谱或扫描件。优先选择出版社正版乐谱、图书馆馆藏和明确属于公有领域的版本。作品进入公有领域不代表现代编辑版、指法排版或录音也不受版权保护。

欢迎补充曲目、准确作品编号、版本信息与合法资源链接。若声称某曲属于某机构的官方级别，请附机构、年份/版本和官方来源。

## 仓库内钢琴谱（SVG）

谱面以 SVG 矢量文件直接保存在仓库中，支持放大查看。当前优先制作一级至三级的入门谱，已有谱面见 [一级曲目](01-一级曲目.md) 与 [二级曲目](02-二级曲目.md)。其余曲目会在逐首核对音高、节奏和授权条件后再补充；不提供外部乐谱检索链接。

目前附有原创简易版：小星星、欢乐颂、玛丽有只小羊羔。它们是教学编配，不是出版版或考级机构官方版本。
